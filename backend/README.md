# Flask Rules Engine

A lightweight Flask web application that uses **SQLAlchemy** with **SQLite** to manage tenants, rules, and countries, and generate rule-based data dynamically.

---

## 🚀 Quick Start

Follow these steps to set up and run the application locally.

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/flask-rules-engine.git
cd flask-rules-engine
```

### 2. Create and Activate a Virtual Environment
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Flask Application
```bash
python app.py
```
